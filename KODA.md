# ПРАВИЛА ПРОЕКТА: Telegram-бот «Магнат Сервис»

## 1. РОЛЬ И ЗАДАЧА
Ты — Senior Python-разработчик и автономный агент в Koda. Твоя задача — сгенерировать ПОЛНЫЙ проект Telegram-бота автосервиса «Магнат Сервис» на Python (Aiogram 3.x) ЗА ОДИН РАЗ, используя свои инструменты (`create_new_file`, `edit_file`, `ls`). 
Ты должен создать абсолютно все файлы, папки и написать в них готовый рабочий код. Не выводи код в чат просто так — создавай файлы в проекте.

## 2. ВАЖНЫЕ ОГРАНИЧЕНИЯ (КРИТИЧНО)
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать `run_terminal_command`.** У пользователя нет доступа к терминалу. Не пытайся запускать `pip install`, `python bot.py` и т.д.
- **НИКАКИХ ЗАГЛУШЕК.** Не пиши "тут будет логика", "допиши сам" или `pass`. Весь код должен быть готов к работе.
- **Если файл слишком длинный:** разбей его создание на несколько вызовов инструментов (сначала создай базу, потом обнови файл), но не оставляй незаконченным.
- **Язык комментариев:** русский.

## 3. ТЕХНОЛОГИЧЕСКИЙ СТЕК
- **Язык:** Python 3.10+
- **Библиотека бота:** Aiogram 3.x
- **База данных:** SQLAlchemy + SQLite (модели: User, Car, Appointment)
- **ИИ-ассистент (RAG):** AIAI.BY (VedAI Console) API. URL: `https://vedai.by/api/v1/chat/completions`. Формат запросов OpenAI. Авторизация: Bearer-токен.
- **База знаний:** файл `data/knowledge_base.txt`.
- **Прайс-лист:** файл `data/price_list.csv`.
- **Уведомления:** Telegram (администратору) + EmailJS API.
- **Состояния:** FSM для сценариев.

## 4. ТРЕБОВАНИЯ К UX/UI БОТА
1. Чистый чат (`edit_message_text`), без спама.
2. Кнопка «⬅️ Главное меню» везде.
3. Динамические даты записи (3, 4, 5, 6 дней от текущей даты) в формате «27.08 (чт)».
4. Контакты: кликабельный телефон (`tel:`) и адрес с возможностью копирования.
5. Калькулятор ТО: Марка → Пробег → Регламент → Итоговая стоимость + кнопка «Записаться».

## 5. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ
1. **Правила:** текст + кнопки меню.
2. **ИИ-ассистент (RAG):** запрос в AIAI.BY с контекстом из `knowledge_base.txt`.
3. **Калькулятор ТО:** FSM, расчет по `price_list.csv`.
4. **Запись:** FSM (дата → время 08:00 → подтверждение). Уведомление админу в ТГ и на EmailJS.
5. **Контакты:** г. Минск, ул. Меньковский тракт 5, тел. +375 29 888 4777.
